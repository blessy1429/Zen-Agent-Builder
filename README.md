# Zen Agent Builder

AI Agent Studio and Workflow Automation Platform

## Features
- Agent Builder
- Workflow Builder
- Knowledge Base
- API Services
- API Analytics
- Execution History
- Agent Marketplace

## Technology Stack
- FastAPI
- SQLAlchemy
- SQLite
- Jinja2
- HTML/CSS/JavaScript

## Run

pip install -r requirements.txt

uvicorn main:app --reload
